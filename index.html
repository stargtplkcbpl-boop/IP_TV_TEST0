❓ STAR TV Help

Operator add नहीं हो रहा?
Operators में username + password भरें और Add Operator दबाएँ. Save के बाद list में operator दिखना चाहिए.

Logo वापस हट/बदल क्यों जाता है?
अब local save और Firebase sync में latest change की timestamp रखी जाती है, इसलिए पुराना Firebase data नया logo overwrite नहीं करेगा.

लाल Welcome notification बंद करें
Appearance में “Show top red notification” untick करके Save Appearance करें. ऊपर notification पर × दबाकर भी तुरंत hide कर सकते हैं.

अगर Firebase offline हो
Settings, logo और operators पहले local browser में save रहेंगे. Internet/Firebase वापस आने पर sync करने की कोशिश होगी.
